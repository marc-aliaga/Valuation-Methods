# Case Study Template

Copy this folder and rename it to the company being valued (e.g. `Case_Studies/Apple_2026/`).

Each case study should contain:

* `model.py` or `model.xlsx` — the applied valuation model, built on one or more of the methods in this repository
* `assumptions.md` — inputs used (growth rates, discount rate, terminal value assumptions, peer set, etc.) and their sources
* `output.md` (optional) — resulting valuation, key sensitivities, and a short interpretation

Keep raw source data (filings, market data) out of version control unless it is small and public; cite sources in `assumptions.md` instead.
